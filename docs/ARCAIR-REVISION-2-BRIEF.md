## 2. 현재 상태 진단 (내가(오케스트레이터) 이미 확인한 사실)

- thezonebio.com/arcair 라이브 버전에 이미 "coordination state" 문단과 "Re-entry/Polling/
  Next-step/Verification 제거" 4가지 카드가 들어가 있음 (grep으로 3곳씩 확인함).
  → 이 내용 자체는 이미 반영됐다. 이번 요청의 핵심은 **내용 추가가 아니라 카피 톤 교정**이다.
- 즉 이번 작업은:
  1. **카피 전면 재작성** — "AI가 쓴 티" 나는 문장(대칭적 3단 구조, "~입니다"가 기계적으로
     반복되는 프레젠테이션 말투, 지나치게 깔끔한 불릿, 상투적 전환구 "그리고", "하지만"
     남발)을 제거하고, 실제 창업자가 말하듯 리듬 있고 키치하게(위트 있고 자기 목소리가
     느껴지게) 다시 쓴다. 문어체 프레젠테이션 톤 대신 구어체에 가까운 대사 흐름, 예상 못한
     비유, 짧고 강한 문장과 긴 문장의 리듬 변주를 섞어라.
  2. **/arca 랜딩 PR #11을 재검토·머지** — Min이 "예전 /arca 로 복원하고, 캐릭터들 잘 살려"
     라고 했으니, PR #11의 diff가 실제로 Spirit 캐릭터/모션이 잘 살아있는지 직접 스크린샷
     찍어 재검증하고, 문제없으면 main에 머지해서 실제 /arca 도메인에 반영한다.
  3. **능동적 자율성 데모 씬 강화** — 이미 8번 슬라이드에 있다고 보고했지만, Min이 다시
     강조하는 걸 보면 부족하거나 안 보였을 가능성. 이 씬을 다음 요소로 명확하게 만든다:
     - ARCA가 대화/회의 전사를 이해한 뒤 스스로 "제가 여기부터 여기까지 처리하고
       보고드릴까요?" 라고 먼저 제안하는 대사
     - 사용자가 승인하면, ARCA가 진행 중 판단이 막히는 지점에서 "레퍼런스 자료 하나만
       주시겠어요?" 처럼 필요한 걸 능동적으로 되묻는 대사
     - 이 흐름이 발표에서 "이 순간이 제일 중요하다"고 Min이 강조한 지점이니, 슬라이드
       타이밍/애니메이션/시각적 강조(줌인, 하이라이트 박스 등)로 이 씬이 확실히 눈에
       띄게 만들어라. 지나가듯 보이면 안 된다.

## 3. 작업 원칙
- **파괴적 재작성 허용**: Min이 "스크립트랑 고정 슬라이드 신경쓰지말고 맘대로 modify해도
  된다"고 명시함. S0~S15 순서/문구에 얽매이지 말고, 투자자 임팩트 기준으로 재구성해도 된다.
- **감도 기준은 arcair-ver1(v2, 23장)과 기존 /arca 랜딩**이다. 이번 v4가 아니라 그 이전
  버전의 톤/무드/모션이 정답이라고 Min이 재확인했다. v4에서 어제 새로 만든 부분 중
  이 감도에서 벗어난 게 있으면 과감히 되돌리거나 다시 써라.
- 카피 검수 기준: 소리 내어 읽었을 때 "이거 사람이 발표하다가 즉흥으로 나온 말 같다" 싶은
  문장을 목표로. 불릿 나열형 프레젠테이션 언어, 과도한 격식체, 뻔한 접속사 전환은 전부 재작성.
