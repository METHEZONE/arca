## 0. 먼저 정할 것 — 히어로가 두 개다

PRD와 실제 제품이 갈라져 있고 이걸 정리하지 않으면 아래 8개 섹션이 전부 두 갈래로 쪼개진다.

| | PRD가 말하는 것 (6/24 locked) | 증거·구현이 말하는 것 |
|---|---|---|
| 히어로 | Flow-State Guardian (Slack 실시간 트리아지) | 회의 → 결정/액션 → 착지·리콜 |
| 근거 | 딥인터뷰 11R (내부 논리) | 40인 인터뷰: "결정을 일주일 안에 잃는다" |
| 코드 | `Features/Zone` **448줄, 7/29 이후 정지** | `Sessions` 1,876 + `Brain` 1,164 + `Record` 817줄, **이번 주 집중 개발** |
| 미구현 | Expedition Report, decision card, ZONE 트리거 (해당 이름의 구현 없음) | — |
| YC 지원서 | — | "AI meeting-assistant market" 으로 이미 이동 |

**권고: 히어로를 "결정 루프 종결"로 확정하고 PRD를 개정한다.**
이유는 세 가지다. (1) 외부 증거(40인)가 그쪽을 가리킨다 — PRD의 근거는 자체 인터뷰라 순환논증에 가깝다. (2) 6개월간 손이 간 곳이 그쪽이다 — 실제 베팅은 코드가 말한다. (3) 가디언은 Slack 쓰기 권한·오조작 리스크·조직 승인이 전제인데 v1 신뢰모델(individual-first)과 상충한다.

Flow Guardian은 **버리지 않고 비전 레이어로 올린다** — "지금은 회의의 결정을 지키고, 다음은 하루 전체의 몰입을 지킨다". 이러면 PRD의 세계관 자산(ZONE·arca it·Spirit)이 그대로 살아있고 IR에서는 확장 서사가 된다.

이하 8개 섹션은 **"결정 루프 종결"을 히어로로 가정하고** 작성했다.

## 1. Target Audience

### 가설 (core, 오늘의 MVP가 맞는 사람)
> **한국어로 외부 미팅을 주 5회 이상 하고, 그 후속 실행이 본인에게 걸려 있으며, 이미 Obsidian/Notion에 기록을 쌓는 습관이 있는 1–5인 규모의 창업가 · BD/세일즈 리드 · 컨설턴트 · 에이전시 대표.**

세 조건을 모두 만족할 때만 core다:
1. **후속이 본인 책임** — 놓친 결정의 비용을 남이 아니라 본인이 문다 (→ painkiller 조건)
2. **한국어 외부 미팅 중심** — 한국어 품질이 차별점이 되는 유일한 구간
3. **이미 second-brain 습관 있음** — Obsidian/Notion 착지 지점이 이미 있어 첫날부터 가치

### End user = Budget holder (초기 강점)
B2B 프레임워크는 보통 사용자와 구매 결정권자를 분리해야 하지만 ARCA v1은 **둘이 동일인**이다. PRD §9의 individual-first 신뢰모델과 정확히 맞물린다 — IT 승인 없이 개인이 자기 카드로 결제한다. 보수적 조직의 게이트키퍼(리서치가 지목한 #1 도입 장벽)를 우회하는 게 설계 의도다.

### Core에서 **제외**할 것
- **현대 직원 코호트** — PRD는 초기 검증 코호트로 잡았지만 급여받는 직원에게 "결정 유실"은 개인 손실로 잡히지 않는다 → **vitamin**. ZER01NE은 core 오디언스가 아니라 **엔터프라이즈 진입 채널(T2/T3)**로 재분류한다.
- **영어권 유저** — 한국어 품질이 차별점인 동안은 우위가 없다. Granola와 정면충돌.
- 학생 · 회의 적은 개발자 — 캡처량이 안 나오면 메모리 모트가 안 쌓인다.

### 미검증 가정
- 이 좁은 정의의 실제 모집단 크기 — **근거 없음**. TAM은 있지만 이 core segment 카운트는 없다.
- "이미 Obsidian/Notion 쓴다"가 얼마나 흔한가 — 40인 인터뷰에 이 질문이 있었는지 불명.

### 검증 방법
- waitlist 50+에 3문항만 던진다: 주 미팅 수 / 후속 책임자 / 현재 노트 도구. core 정의에 몇 %가 걸리는지 센다.
- core 정의를 만족하는 10명에게만 온보딩 → 이들의 W4 리텐션 vs 나머지 비교.

## 2. Problem You're Solving

### 가설
> **회의는 하는데 결정이 남지 않는다.** 기록이 없어서가 아니라, (a) 결정이 어디 있는지 모르고 (b) 후속이 실행되지 않고 (c) 필요한 시점에 다시 떠오르지 않기 때문이다.

### 있는 근거 (가장 단단한 자산)
- 40인 인터뷰 반복 문장: **"우리는 모든 결정을 일주일 안에 잃는다"**
- "People don't want another archive. They want the loop closed" (YC 지원서) — 사용자 언어로 문제가 정의돼 있다. 이건 그대로 카피로 쓸 수 있는 수준.

### 이전 시도들 (문제 공간의 역사)
| 기존 해법 | 왜 실패하나 |
|---|---|
| 수동 회의록 | 애초에 안 씀. 쓰더라도 결정만 추출되지 않음 |
| 네이버 클로바노트 | 전사는 훌륭. **실행·리콜이 0** — 텍스트 무덤이 하나 더 생김 |
| Notion 수동 정리 | 2주면 붕괴. 정리 비용이 가치보다 큼 |
| Granola / Otter | 노트까지만. 영어권 최적화 |
| 사람 비서 | 비용. 1–5인 규모에 불가 |

### Painkiller vs Vitamin — 정직한 판정
**세그먼트에 따라 갈린다.** 딜·계약 후속이 본인에게 걸린 창업가/BD에게는 놓친 후속 = 잃은 매출이라 **painkiller**. 대기업 직원에게는 아무도 해고되지 않으므로 **vitamin**. 이 갈림이 §1의 좁힘을 정당화한다 — 같은 제품이 세그먼트에 따라 진통제이거나 비타민이다.

### 미검증 가정
- "결정 유실"의 **금액 환산** — 근거 없음. painkiller 주장을 뒷받침할 숫자가 없다.

### 검증 방법
- core 10명에게: "최근 3개월에 후속을 놓쳐서 실제로 잃은 건(딜·신뢰·재작업)을 하나 말해달라." 금액이 나오면 painkiller가 증명된다. 못 나오면 vitamin이다.

## 3. Value Propositions (3개로 제한)

고객 언어로, 기능이 아니라 약속으로.

1. **"루프가 스스로 닫힌다."**
   회의가 끝나면 노트가 아니라 *다음 행동*이 나온다 — 후속 메일 초안, 캘린더 이벤트, 투두. 정리할 게 남지 않는다.
   → 구현 상태: 액션아이템 추출·Notion/Obsidian 착지·투두 생성 있음. **자동 발송은 승인 게이트 뒤에 있음.**

2. **"결정은 살아남고, 때맞춰 돌아온다."**
   누가 무엇을 왜 결정했는지가 구조화돼 남고 관련 상황에서 다시 떠오른다.
   → 구현 상태: 이번 주 요약 스키마 개편(주제별·근거·결정자·미해결질문)으로 "왜"까지 남기 시작. **리콜(때맞춰 다시 떠오름)은 미완** — Phase F에서 "server-side session content가 없어 막힘"으로 문서화됨.

3. **"손대지 않아도 잡힌다."**
   워치·폰·맥 어디서 시작해도, 앱을 나가도, 전화가 와도 안 끊긴다.
   → 구현 상태: **이번 주에야 사실이 됐다.** 그 전엔 앱 나가면 세션이 통째로 소실됐다.

### 미검증 가정
- 세 개 중 어느 것이 실제 구매 이유인지 — 근거 없음. 지금은 세 개를 동등하게 말하고 있다.

### 검증 방법
- 랜딩 3버전(각 밸류프롭 하나씩 헤드라인) A/B → waitlist 전환율. 가장 높은 것을 히어로 카피로.

## 4. Strategic Differentiation

### 진짜 차별점 (방어 가능)
1. **한국어 회의 품질 + 한국 업무 맥락.** 미국 제품은 한국어를 후순위로 둔다. 여기에 카톡(향후)·ISMS-P·한국 데이터 리전까지 로드맵으로 붙어 있다 — 글로벌 인컴번트가 따라오기 구조적으로 느린 구간.
2. **노트가 아니라 실행.** 전사·요약에서 멈추지 않고 착지(Obsidian/Notion/Slack)와 실행(투두·캘린더·메일 초안)까지 간다. 카테고리를 "회의 기록"에서 **"위임"**으로 옮기는 근거.
3. **캐릭터/컴패니언 (Spirit·도깨비).** 인컴번트 중 누구도 정서적 애착 자산이 없다. 리텐션 기제이자 마케팅 자산(§6에서 ARCA가 자기 X 계정을 운영) — **가장 모방하기 어려운 축.**
4. **멀티서피스.** 워치에서 시작해 노치에서 끝난다. 항상 몸에 붙어 있는 캡처.

### 차별점이 **아닌** 것 (정직하게)
- **전사 정확도 자체는 우위가 아니다.** 이번 주에 한국어 9% → 95%대로 살렸지만 그건 우위 확보가 아니라 **결함 수정**이었다.
- **화자분리를 잃었다.** whisper-1 전환의 대가. 회의 제품에서 "누가 결정했나"는 핵심인데 현재 마이크(나) vs 시스템오디오(상대 전부)로만 갈린다. 요약 프롬프트가 발화 내용에서 이름을 추출하는 우회책으로 버티는 중.
- **10x 주장은 "한국어+실행+애착" 축에서만 가능.** 순수 전사 품질로 Granola를 이긴다는 주장은 현재 근거가 없다.

### 검증 방법
- 클로바노트 유저 5명에게 같은 회의를 양쪽으로 돌리고 "어느 쪽에 월 2만 원 낼 건가 + 왜"를 묻는다. "실행"이 이유로 나오면 #2가 검증된다.

## 5. Competition

| 경쟁자 | 강점 | 우리가 이기는 논리 |
|---|---|---|
| **네이버 클로바노트** (실질 1위) | 무료, 한국어 강함, 전 국민 인지 | 전사가 아니라 **실행·리콜**. "텍스트를 주지 않고 다음 행동을 준다" |
| **Granola** | 맥 네이티브, 노트 UX 최고 | 한국어 + 실행 + 착지 |
| Otter / Fireflies | 엔터프라이즈 전사, 통합 | 한국어, 개인 바텀업(IT 승인 불필요) |
| Notion AI | 이미 워크스페이스 안에 있음 | 캡처를 안 함 — 우리는 Notion으로 *배달*한다 (경쟁 아닌 보완) |
| **아무것도 안 함 (진짜 status quo)** | 비용 0, 관성 최강 | 이게 실제 상대다. 전환 비용 < 즉시 가치를 첫 세션에 증명해야 함 |

**가장 위험한 칸은 클로바노트다.** 무료 + 한국어 강자에게 "왜 유료를 쓰냐"에 대한 한 문장 답이 현재 문서 어디에도 없다. 이건 §4 #2(실행)로만 답할 수 있고 그래서 액션아이템 종결률이 KPI 1순위가 된다.

## 6. Acquisition Strategy

### 가설: 데모 주도 바텀업 PLG
- **엔진**: 킬러 데모 1개 (Farza 공식 — 꾸준함보다 한 방 설계). 3개 후보 중 **The Loop("워치에 arca it → 42초 후 Notion 착지")가 PMF에 가장 근접** — 밸류프롭 3개를 한 컷에 증명한다. Ring은 훅이 세지만(리콜) 제품 코어가 아니고 Hatch는 감정 훅이지만 문제 해결을 안 보여준다.
- **채널**: X(글로벌·YC 앵글) 발견 → IG Reels 전환 → thezonebio.com/arca 랜딩 → 웨잇리스트 → founding $19 락인.
- **메타 플레이**: ARCA가 자기 X 계정(@heyarca)을 운영하며 매일 위임 리포트를 올린다. **마케팅이 곧 제품 증명** — 이건 경쟁자가 복제할 수 없는 포맷(제품이 실제로 작동해야 성립).
- **오프라인**: NFC 링(thezonebio.com/arcaconnect 라이브) — 행사에서 탭 → 재회 히스토리. 리콜 밸류프롭의 실물 데모.
- **엔터프라이즈 경로**: ZER01NE/현대는 획득 채널이 아니라 **T3 전환 파이프라인**. 바텀업으로 조직 내 확산 후 보안리뷰 트리거 시 전환(PRD §9.5 GTM).

### 미검증 가정 (가장 취약한 섹션)
- **CAC 전혀 모름.** 채널별 획득 비용 데이터 0.
- waitlist 50+ → 유료 전환율 미지.
- 데모 영상 → 가입 CVR 미지. (Farza의 3M뷰는 그의 팔로워 116.7k 기반이고 우리는 아님)

### 검증 방법
- The Loop 데모 1개를 만들어 X+IG 동시 배포 → 뷰/가입/유료 퍼널을 처음으로 계측한다. 이 숫자 없이는 §6 전체가 가설이다.

## 7. Monetization Strategy

### 현재 상태와 불일치
| 소스 | 가격 |
|---|---|
| 랜딩 + YC 지원서 | **$0 / $19 / $99** (founding $19 평생 락, 선착 1,000) |
| PRD §13.5 | ₩0 / **₩12,900** / ₩19,900/seat |
| WTP 설문 | 개인 **₩5k–30k/mo** |

**$19 ≈ ₩26,000 = PRD의 2배이고 WTP 구간의 상단.** 이 불일치를 먼저 정리해야 한다. 권고는 **$19 유지** — WTP 상단 앵커링 + founding 평생락은 "지금 사면 이득" 압력을 만들고 나중에 내리기는 쉽지만 올리기는 어렵다. 대신 무료 티어가 첫 가치를 확실히 주도록(회의 3건/월 정도) 설계.

### 구조적 전환점 — 이번 주에 생긴 새 리스크
지금까지는 **BYOK**(유저가 자기 API 키를 넣음)라서 원가가 0이었다. 이번 주 서버 키 미터링을 구현하면서 **원가를 우리가 지게 됐다.** 진짜 구독이 가능해진 대신:
- 1시간 회의당 전사+요약 원가를 **아직 계산하지 않았다** → gross margin 미지
- $19에 무제한을 주면 헤비유저에서 마진이 깨질 수 있다
- Phase 4의 쿼터(월 50/2,000/5,000)는 **추정치이고 실제 원가 기반이 아니다**

### 검증 방법
- 1시간 한국어 회의 1건의 실제 API 원가를 측정한다(whisper-1 + Claude 요약). $19 ÷ 원가 = 손익분기 회의 수. 이게 쿼터 설계의 유일한 근거가 돼야 한다.
- Y3 목표 120K 유료 ≈ $21.6M ARR = **$15/mo/user** → $19 대비 할인·이탈 감안 시 정합적. 단 gross margin이 붙어야 의미가 있다.

## 8. KPIs

### North Star
> **주간 "닫힌 루프" 수 = 캡처된 회의 × 액션아이템 종결률**

기록량(캡처 수)만 보면 클로바노트와 같은 지표가 된다. **종결률을 곱한 지표만 카테고리 주장(위임)과 일치한다.**

| 층 | 지표 | 벤치마크(초기 추정) |
|---|---|---|
| Acquisition | 데모 뷰→가입 CVR, waitlist→활성 전환 | 미지 — 첫 측정 필요 |
| Engagement (가치 대리) | 주당 세션 수, **액션아이템 종결률**, 리콜 쿼리 수 | 종결률 40%+ 목표 |
| Retention | W1 / W4 리텐션 | 생산성 SaaS W4 통상 20–30% |
| **Irreversibility (모트)** | **D30/D90 누적 메모리 크기** — 스위칭 코스트 대리 | 신규 지표, 벤치마크 없음 |
| **Quality gate** | 한국어 전사 정확도, 요약 유용성 평점 | **95%+ / 4.0+ 필수** |
| Monetization | 무료→유료 전환율, ARPU, **gross margin/user** | PLG 무료→유료 통상 2–5% |

**Quality gate를 KPI로 승격시킨 이유**: 이번 주에 한국어 전사가 9%였다는 걸 발견했다. 캡처가 부정확하면 위의 모든 지표가 무의미해진다 — 잘못된 요약은 마이너스 가치다. 이건 "잘하면 좋은 것"이 아니라 **다른 지표를 볼 자격을 주는 게이트**다.

## 9. PMF 블로커 — 서사 자체를 무너뜨리는 3개

기술 부채가 아니라 **위 가설이 성립하지 않게 만드는** 것들.

1. **크로스디바이스 메모리 싱크가 없다.**
   `SyncBackend.swift`는 미구현 스텁이고 CloudKit 미러링이 안 붙어 있다. 같은 계정의 두 기기가 **조용히 갈라진다.** → 이건 "누적 메모리 = 스위칭 코스트"라는 **모트 주장을 직접 무효화**한다. §8의 Irreversibility 지표를 측정할 대상 자체가 하나의 코퍼스로 존재하지 않는다. **1순위.**

2. **화자분리 상실.**
   "누가 무엇을 결정했나"는 결정 루프 제품의 심장인데 현재 상대방 여러 명을 구분하지 못한다. §3 밸류프롭 #2와 정면 충돌.

3. **클로바노트에 대한 답이 없다.**
   한국 시장 최대 경쟁자(무료·강력·전국민)에게 "왜 돈을 내냐"의 한 문장이 없다. §5의 빈칸.
