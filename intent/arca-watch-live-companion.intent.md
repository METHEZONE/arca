# Intent — 워치 메인 화면: 컴패니언 하나에 세 제스처 (대화 · 녹음 · 빠른 메모)

작성 2026-09-17 · 요청자 민성 · 브랜치 `watch-live-main`

## 왜

지금 워치 앱은 "얼굴을 탭하면 녹음" 하나뿐이다. 민성의 요청: 손목에서 ARCA와 **실시간으로 대화**(GPT live)하고, **회의 녹음**과 **잠깐 말해두는 메모**를 손가락 하나로 구분해서 시작하고 싶다. 워치는 하루 중 ARCA가 가장 가까이 있는 표면이라, 이 셋이 메인 화면이어야 한다.

## 무엇 (사용자 관점)

1. **메인 = 컴패니언.** 화면 가운데 ARCA. 세 제스처:
   - **한 번 탭** → 대화 시작/종료. ARCA가 듣고(파란 링), 말한다(몸이 소리 크기에 맞춰 통통). 말이 끝나면 다시 듣는다. 다시 탭하면 끝.
   - **두 번 탭** → 회의 녹음 시작/정지 (지금과 같은 초록 링 + 타이머).
   - **꾹 누르기** → 누르는 동안만 녹음(빠른 메모). 손을 떼면 저장되어 아이폰으로 간다. 주황 링, 몸이 귀를 기울이듯 살짝 기울어진다.
   - 각 상태는 **보는 순간 구분**되어야 한다: 링 색(파랑/초록/주황) + 눈/몸 모션 + 한 줄 캡션.
2. **오른쪽 위 설정 버튼** → 언어(한국어/English/시스템), 대화 음성 켬/끔, 진동.
3. **한 칸 아래(아래로 스와이프) = 할 일 목록.** 아이폰의 ARCA 할 일이 그대로 보이고, 탭해서 완료할 수 있다. 그 아래로 기존 요약·컨디션 측정 페이지.
4. **대화 내용은 사라지지 않는다.** 끝나면 아이폰 채팅 기록에 "워치 대화"로 남는다. ARCA는 대화할 때 이미 아는 것(기억)을 알고 있어야 한다.
5. **전부 한국어.** 워치 기본 언어는 한국어(설정에서 바꿀 수 있음).

## 아닌 것 (Non-goals)

- 워치 단독 사용(아이폰 없이): 대화 시작에 아이폰이 근처에 있어야 한다. 아이폰이 없으면 그렇게 말해준다.
- 백그라운드 대화: 대화는 화면이 켜진 동안만.
- 워치에서 요약 생성·전사: 지금처럼 아이폰이 한다.
- 새 캐릭터 그리기: 지금 워치의 오렌지 스피릿에 상태별 모션만 추가.

## 성공 기준 (acceptance)

- AC-1 메인 화면에서 세 제스처가 각각 다른 상태를 열고, 캡션·링·모션으로 1초 안에 어떤 상태인지 알 수 있다.
- AC-2 한 번 탭 후 한국어로 말하면 ARCA가 한국어 음성으로 답하고, 되묻기가 자연스럽게 이어진다(서버 VAD). 말하는 도중 끼어들면 ARCA가 멈춘다.
- AC-3 대화 종료 후 아이폰 채팅 탭에 그 대화가 남아 있다.
- AC-4 꾹 눌러 5초 말하고 떼면, 아이폰 라이브러리에 "빠른 메모 …" 세션이 생기고 전사가 붙는다.
- AC-5 아래로 스와이프하면 아이폰 할 일이 보이고, 하나를 완료하면 아이폰에서도 완료된다.
- AC-6 오른쪽 위 기어 → 설정. 언어를 English로 바꾸면 워치 전체가 영어가 된다.
- AC-7 워치·아이폰 모두 영어 하드코딩 문구가 메인 화면·탭·기본 제목에 남아 있지 않다.

## 열린 질문 → 기본값으로 진행

- 라이브 모델: OpenAI `gpt-realtime` (민성 지정 "GPT live"). 목소리 `marin`.
- 키: 아이폰이 OpenAI에서 임시 client secret을 발급해 워치에 넘긴다(민성 = 자기 키, 초대 테스터 = ARCA Cloud가 발급). 워치는 키를 갖지 않는다.
- 대화 컨텍스트: 발급 시 `instructions`에 ARCA 페르소나 + 기억 요약(MemoryPrompt)을 넣는다.
